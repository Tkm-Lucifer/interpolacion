# Métodos Numéricos - Lucifer

Repositorio de la materia de **Métodos Numéricos**. Aquí se documentan las 6 unidades del curso con teoría, problemario y códigos en Python.

## Estructura del repositorio

```
Unidad_X/
├── 1-Teoria-Organizacion/   ← Teoría y conceptos del tema
├── 2-Problemario/           ← Problemas resueltos
└── 3-Codigos/               ← Implementaciones en Python
```

| Unidad | Tema |
|--------|------|

| Unidad 2 | Métodos de Aproximación de Raíces |
| Unidad 3 | Sistemas de Ecuaciones Lineales |
